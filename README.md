# Sous le Ciel Austral

![Aperçu du site Sous le Ciel Austral](https://pub-7419959f05894755bb36f1ce35374c6a.r2.dev/images/index/taaf_reduite.webp)

## À propos du projet

Sous le Ciel Austral est un site consacré à mon expérience dans les Terres australes et antarctiques françaises, plus particulièrement sur l’archipel de Crozet.

J’y partage des photographies, des récits et des témoignages autour de l’Hivernage 62 sur l’Île de la Possession. Le site présente aussi les personnes présentes sur place, leurs métiers et leur quotidien.

Ce projet me sert également à apprendre le développement web. C’est actuellement mon principal projet personnel et mon portfolio. Il n’est pas terminé et continuera à évoluer avec mes connaissances, mes idées et les nouvelles choses que je souhaite tester.

## Le site

Le site est accessible à cette adresse :

[https://sous-le-ciel-austral.fr/]

## Pourquoi j’ai créé ce site

J’ai commencé ce projet pour garder une trace de cette aventure et la partager avec d’autres personnes.

J’ai ensuite décidé de m’en servir pour progresser en développement web sur un sujet qui me tient vraiment à cœur. Cela me permet d’apprendre en travaillant sur un projet concret plutôt qu’en réalisant uniquement de petits exercices séparés.

Au fil du temps, j’y ai ajouté plusieurs éléments :

- différentes pages consacrées aux lieux, aux équipes et aux missions ;
- des galeries de photographies ;
- un affichage agrandi des images ;
- des animations au défilement ;
- un menu adapté aux téléphones et aux tablettes ;
- des interviews et des présentations interactives ;
- un formulaire de contact et un livre d’or.

## Technologies utilisées

Le projet est principalement réalisé avec :

- HTML ;
- CSS ;
- JavaScript ;
- Cloudflare R2 pour stocker et diffuser les images et les videos ;
- Render pour héberger l’API du livre d’or.

Je n’utilise pas encore de framework pour ce site. Mon objectif est d’abord de bien comprendre les bases avant d’aller vers des outils plus avancés.


## Organisation du projet

```text
.

│   └── data/      # Fichiers JavaScript

```
